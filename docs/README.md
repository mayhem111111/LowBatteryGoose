## Publication and verification standard

These documents distinguish confirmed facts from plans and proposals. Any mint address, wallet address, token balance, purchase amount, transaction signature, signer configuration, or deployment status must be independently checked before being described as verified or live.

The universal project policy is that **no project-controlled token or fund may be released without at least two independent authorized signatures**. A written policy is not proof that the relevant multisignature wallet has been configured; publish the wallet, signer set, threshold, and verification evidence only after confirmation.

The Markdown files are the canonical source documents. The website's styled document pages should reproduce these documents and provide a print-to-PDF option. A browser print option is not itself a published PDF attachment.
