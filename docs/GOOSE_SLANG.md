# The Goose Lexicon 🪿🔋
Slang, slogans, captions and hashtags for X, Telegram, memes and Spaces.
Safe for public use: fun, community and battery jokes only. Never pair them with price claims ("moon", "100x", "pump it").

| **Honk out** | Go all in on the vibe, be loud | "It's launch night. Honk out." |
| **Honked** | Hyped, excited | "I'm so honked for tonight" |

| **Goof** | A gloriously dumb moment | "Spilled coffee on my keyboard. Certified goof." |
| **Goof troop** | Your group of friends in the flock | "Bringing the whole goof troop tonight" |
| **1%er** | Someone running on almost nothing but still showing up | "Proud 1%er since Monday" |
| **Low batt** | Tired but present | "Low batt but here for the Space" |
| **Dead batt** | Completely done | "Dead batt. Honking from the grave." |

| **Recharge** | Rest, or the community lifting you up | "The flock is my recharge" |
| **Plugged in** | Active, paying attention | "Stay plugged in, honkers" |
| **Unplugged** | Gone quiet, inactive | "Who unplugged? Roll call 🪿" |
| **Power-saving mode** | Lurking | "Still in power-saving mode, just reading" |
| **Charging** | Getting ready | "Charging for the Space at 5:30" |

| **Honk responsibly** | Be kind, no scams, no spam | Sign-off for safety posts |
